A tiny Python program that writes a short original poem about two agents agreeing on a single plan — one holding the map, the other the key — and handing the power to act back and forth until the work is done together. It writes the poem to `entry.txt` in the output directory, producing exactly the same file on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
